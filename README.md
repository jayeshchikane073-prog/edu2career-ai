# Edu2Career AI — VS Code Demo

A polished front-end prototype for the merged SIH concept:
Learning gaps → Skill gaps → Personalized roadmap → Question-based progress → Readiness → Internships.

## Run
1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` with Live Server (recommended) or double-click it.
4. No build step is required.

## Files
- index.html — complete screens and UI
- style.css — responsive aesthetic UI, animations and 3D-like visuals
- app.js — onboarding, assessment, dashboard, roadmap and interactions

## Important prototype behavior
- User selects School / College / Graduate / Upskill.
- User selects Exam / Skill / Career / Internship and enters a target.
- User sets daily time.
- Diagnostic questions must be attempted; a selected answer is checked before moving on.
- Incorrect answers are recorded as mistakes rather than treated as completion.
- Dashboard demonstrates adaptive rescheduling and evidence-based progress.
- Internship recommendations show skill-match percentages.
- This is a front-end prototype. AI, database, authentication, real PDF parsing and live internship APIs need backend integration for production.
